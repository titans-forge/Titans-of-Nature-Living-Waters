# Itch.io Page Copy

## Short description

Fish fifteen living waters, read their ecosystems, and discover why the catch is only part of the story.

## Description

**Titans of Nature: Living Waters** is a free, local-first educational fishing expedition across the Amazon, Okavango, Tonle Sap, Florida Bay, Alaska, Lake Baikal, the Nile, the Ganges, the Great Barrier Reef, and more.

Ask local guides what changed. Choose equipment. Read water, plants, current, and season. Then manage the line, handle each encounter responsibly, and return with a field record that connects fish to the larger ecosystem.

- Fifteen complete destinations
- Fish, turtles, plants, invertebrates, snags, and passive wildlife surveys
- Guided mode for an accessible first expedition
- Field mode for players who want to infer the route themselves
- Untimed accessibility controls
- Local progress saving with no account, AI service, or internet connection required after loading
- Authority sources available through the field journal

This is an educational simulation, not current fishing, access, or wildlife-handling guidance. Always verify local rules before real activity.

## Browser instructions

Select **Run game**. The first screen lets you search or scroll through all fifteen destinations. For the easiest introduction, choose the Amazon and leave **Guided** selected. Use the accessibility button in the upper-right corner for untimed casting and line control.

Progress is stored locally in the browser. Clearing browser site data resets the field journal.
