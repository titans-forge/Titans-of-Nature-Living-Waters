# Contributing

Living Waters accepts focused corrections and additions that preserve deterministic, local-first play.

## Before submitting

1. Open an issue describing the factual, mechanical, accessibility, or presentation problem.
2. Keep changes scoped to one destination or one shared system when possible.
3. Add an authoritative source-ledger entry for new factual material.
4. Record media origin and redistribution status separately from the MIT-licensed code.
5. Run `npm run check` and include the result with the contribution.

New venues require internally consistent questions, gear, habitats, encounters, seasonal rules, handling outcomes, source metadata, and media-rights status. Unresolved occurrence, protection, access, or provenance questions should remain outside the public build.
